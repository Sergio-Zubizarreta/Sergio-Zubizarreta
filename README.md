## 🚀 Projects

- **[Shaderpedia](https://github.com/Sergio-Zubizarreta/Shaderpedia) (iOS · SwiftUI · Metal):**  
  An educational iOS app built with SwiftUI that covers fundamental shader topics, with interactive examples written in **Metal Shading Language**. Built as the capstone project for my Swift Verified Developer certification.

- **[Blender Add-on Explorer](https://github.com/Sergio-Zubizarreta/Blender_AddOn_Explorer_Streamlit) (Python · Streamlit):**  
  A Streamlit web app that helps Blender learners and developers discover add-ons on GitHub. Search repositories tagged `blender-addon`, filter by stars, last update, and language, and explore results in an interactive table with a language breakdown chart.

- **INIT Build Program @ FIU (VR):**  
  My team developed a mixed-reality creature-battling RPG using QR code recognition with the Meta Quest 3 headset. Our system uses computer vision to detect physical QR code cards, dynamically spawning 3D creature prefabs spatially anchored to the real world.  
  - **Game Modes:**  
    - _2-Player over Wifi_: Elementally imbued Type battle system with 3 "Vectormon" types.

- **_Of Stars and Twilight_ — 2.5D Pixel Art RPG (In Design):**  
  I'm prototyping a **Zelda-like/JRPG** hi-res pixel art game with **dynamic lighting** and **volumetric effects**, inspired by my favorites: _Sea of Stars_, _Owlboy_, and upcoming releases like _Alabaster Dawn_ (Radical Fish Games) and _Threads of Time_ (Riyo Games).
